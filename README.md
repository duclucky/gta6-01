Palma Bay: an original open-world crime game in the browser. Drive and steal cars, outrun the police, and run missions across a sun-soaked fictional coastal city. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD to move and drive, E to enter or exit a car, Space for the handbrake, mouse click to shoot on foot, P to pause, M to mute. No network needed: the game is static files under game/.
